# QuestLog — Developer Documentation

A gamified habit tracker PWA built with Vite, vanilla JS, and Supabase.

## Architecture

```
QuestLog/
├── src/
│   ├── lib/
│   │   ├── supabase.js     — Supabase client singleton (reads VITE_* env vars)
│   │   └── utils.js        — Pure utility functions (XP math, escaping, dates)
│   ├── styles/
│   │   ├── app.css         — Main app styles (design tokens, layout, all components)
│   │   ├── auth.css        — Auth page styles
│   │   └── landing.css     — Landing page styles
│   ├── main.js             — App shell entry: boot, render pipeline, CRUD, tabs
│   ├── auth-entry.js       — Auth page entry
│   └── landing-entry.js    — Landing page entry
├── public/
│   ├── sw.js               — Service worker (classic, for Firefox compat)
│   └── manifest.json       — PWA manifest
├── index.html              — App shell HTML (multi-page Vite entry)
├── auth.html               — Auth page
└── landing.html            — Landing page
```

## Key Modules

### `src/lib/utils.js`
Pure, side-effect-free functions used throughout the app. **Fully unit-tested.**

- **XP/Level curve** — `xpForLevel(lvl)`, `getCharLevel(totalXP)`
- **Character titles** — `getCharTitle(level)` with 10 tiers (Apprentice → Legend)
- **Streak multipliers** — `getStreakMultiplier(streak)` (1.0× – 1.5×)
- **XSS safety** — `escapeHtml(str)` applied to all user content in innerHTML
- **Dates** — `todayStr()`, `formatDate(iso, opts)`

### `src/lib/supabase.js`
Singleton Supabase client. Reads `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY`
from environment variables — never hardcode credentials.

### `src/main.js`
App entry point. Initialises authentication, loads all data, renders the UI.

Feature modules (inline in main.js, will be extracted to `src/modules/` incrementally):
- **Task CRUD** — add/edit/delete tasks across daily, weekly, backlog categories
- **Backlog Archive** — completed backlog tasks filed by month, permanently deletable
- **Streak reset + shield** — missed-day detection on boot, shield milestone rewards
- **Goal CRUD** — full lifecycle with difficulty tiers, XP/gold rewards, sub-task links
- **Calendar view** — monthly grid with task/deadline overlays
- **Leaderboard** — opt-in, XP-ranked, 5-minute cache

## Environment Variables

Copy `.env.example` → `.env.local` and fill in your Supabase project credentials:

```
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-publishable-anon-key
```

For GitHub Actions deployment, add these as **repository secrets** under
Settings → Secrets → Actions: `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY`.

## SQL Migrations

Run in Supabase Dashboard → SQL Editor after each phase:

```sql
-- Phase 1 (Task CRUD)
ALTER TABLE tasks ADD COLUMN IF NOT EXISTS completed_at timestamptz;

-- Phase 2 (Backlog Archive)
ALTER TABLE tasks ADD COLUMN IF NOT EXISTS archived_at timestamptz;
ALTER TABLE tasks ADD COLUMN IF NOT EXISTS archive_month text;

-- Phase 3 (Streak Shield)
ALTER TABLE character ADD COLUMN IF NOT EXISTS streak_shield integer DEFAULT 0;
ALTER TABLE character ADD COLUMN IF NOT EXISTS last_activity_date date;
ALTER TABLE character ADD COLUMN IF NOT EXISTS awarded_shield_milestones jsonb DEFAULT '[]';

-- Phase 4 (Goals)
ALTER TABLE goals ADD COLUMN IF NOT EXISTS difficulty text DEFAULT 'med';
ALTER TABLE goals ADD COLUMN IF NOT EXISTS xp_reward integer DEFAULT 500;
ALTER TABLE goals ADD COLUMN IF NOT EXISTS gold_reward numeric(8,2) DEFAULT 250;
ALTER TABLE goals ADD COLUMN IF NOT EXISTS time_horizon text DEFAULT 'monthly';
ALTER TABLE goals ADD COLUMN IF NOT EXISTS category text DEFAULT 'personal';
ALTER TABLE goals ADD COLUMN IF NOT EXISTS completed_at timestamptz;
ALTER TABLE tasks ADD COLUMN IF NOT EXISTS goal_id uuid REFERENCES goals(id) ON DELETE SET NULL;

-- Phase 8 (Notes)
ALTER TABLE tasks ADD COLUMN IF NOT EXISTS notes text;

-- Phase 7 (Leaderboard)
ALTER TABLE profiles ADD COLUMN IF NOT EXISTS show_on_leaderboard boolean NOT NULL DEFAULT false;
```

## Running Locally

```bash
cp .env.example .env.local   # add your Supabase credentials
npm install
npm run dev                  # http://localhost:5173/QuestLog/
```

## Testing

```bash
npm run test:run    # run all tests once
npm run coverage    # run with coverage report
npm test            # watch mode for development
```

## Building Docs

```bash
npm run docs        # generates docs/api/ from JSDoc comments
```

Docs are auto-generated by GitHub Actions on every push to `main`.
